   - `it's` → `it is`
   - `couldn't` → `could not`
   - etc.

2. **Image URLs causing issues** - Removed all external URLs

   - `public/videos/` - Created ✅

   - Red-bordered placeholders when images missing
   - App works perfectly without images
   - Images appear automatically when added
